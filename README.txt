Egner Fracht- und Gewichtsrechner – Lernprojekt

Dateien:
- index.html: Rechner mit vorhandener Berechnungslogik und mobilfreundlichem Layout
- Egner_Logo_cmyk.png: Egner-Logo im Kopfbereich
- manifest.json: Einstellungen für die Installation als Web-App
- icon.svg: App-Symbol
- service-worker.js: einfache Offline-Unterstützung nach erstem Laden

Lokal testen:
1. ZIP vollständig entpacken.
2. index.html im Browser öffnen.

Hinweis: Für die PWA-Installation und den Service Worker muss die Seite über HTTPS oder localhost aufgerufen werden. Die Entfernung wird weiterhin manuell aus Google Maps übernommen. Bitte Frachttarife und Ergebnisse vor einem produktiven Einsatz prüfen.
